# Test coverage review

Review the test coverage of the cloned repository.

1. Read the contributor docs of the repository and run its tests as they
   describe.
2. Find the behaviour that no test exercises. Look first at error handling and
   at the edge cases of the input of public functions.
3. Choose the three gaps whose defects would affect users the most.

End the run with a report. For each gap, state its file and line, the untested
behaviour and a sketch of a test that covers it. Leave the repository unchanged.
